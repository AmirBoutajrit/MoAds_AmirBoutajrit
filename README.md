MoAds – Ad Creation Platform

MoAds is a mock advertising platform I built. Focused on ad creation and design. Everything is a mock not working to a full extent Visit it live at https://mo-ads-mu.vercel.app .

What It Does

MoAds lets you quickly create and export professional ad graphics. You enter your ad details headline, description, call to action, and platform. and the app automatically generates

A 1200×630 PNG graphic ready for social media

A JSON file containing all your ad data

A dashboard to view and manage your ads

Features

Ad creation with live preview and export (PNG + JSON)

Dashboard with mock analytics and ad details

Canvas based graphics with nice gradients

Light and dark theme support

Multiple pages: Home, Features, Pricing, Dashboard, Contact

Smooth animations and responsive design

Tech Stack

Next.js 16 | Tailwind CSS v4 | TypeScript | Canvas API | Vercel Deployment

Limitations

Ads don’t persist after refresh (no database yet)

Contact form doesn’t send messages

Analytics are mock data

No authentication or real ad publishing
